NOTE TECHNIQUE

Confidentialité et non-stockage des données personnelles

Produit: Client Form Version: 2026 Auteur: Guilhem Normand

1. Résumé exécutif

Cette note répond à la question : « Comment l'application garantit-elle que les informations client ne sont sauvegardées nulle part ? »

La réponse est structurelle : l'application agit comme un miroir numérique. Les données saisies par le client se reflètent en temps réel sur l'écran du conseiller, sans passer par aucun serveur ni base de données. Dès la fermeture de la session, les données disparaissent.

2. Architecture : fonctionnement du miroir

La transmission s'effectue via WebRTC (Web Real-Time Communication), une technologie de connexion directe P2P standardisée par le W3C.

Appareil clientSaisit ses données
⟶
Canal WebRTC P2PChiffrement de bout en bout
⟶
Écran conseillerAffiche en temps réel

Aucun serveur intermédiaire ne touche les données. Le serveur de signalisation agit uniquement comme un annuaire téléphonique pour établir le canal, puis disparaît.

4. Garanties techniques

4.1 Aucune base de données clients

Le code source a été audité et ne contient aucune instruction d'écriture de données personnelles. Les fonctions accèdent uniquement aux métadonnées des licences.

4.2 Chiffrement de bout en bout

WebRTC utilise DTLS pour les données. Aucun noeud intermédiaire ne peut lire le contenu.

4.3 Éphémère par design

Le code de session est détruit à la fermeture. Aucune persistance dans les cookies ou le stockage local.

4.4 Zéro log serveur

Les requêtes P2P sont directes. Les en-têtes HTTP bloquent la mise en cache (Cache-Control: no-store).

5. Cycle de vie d'une donnée

  • ▸ Le client tape son e-mail.
  • ▸ Le script empaquette les données en RAM.
  • ▸ L'objet est envoyé via WebRTC chiffré directement au conseiller.
  • ▸ Le conseiller reçoit et affiche la donnée.
  • ▸ Aucun appel HTTP POST n'est fait avec ces données.
  • ▸ À la fermeture, la RAM est vidée. Aucune copie n'existe.

6. Conclusion

  • Respecte le principe de minimisation du RGPD (Art. 5.1.c).
  • Aucune base de données clients. Les données ne touchent pas de serveur.
  • Canal P2P chiffré de bout en bout.
  • Stockage KV restreint aux données de licences agence et au registre légal.
