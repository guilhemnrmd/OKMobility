Les réponses techniques que votre direction IT, votre DPO ou votre service achats attendent.

Aucune base de données client. Les données personnelles transitent en P2P chiffré AES et ne touchent jamais un serveur. Rien à voler.

Comment savons-nous que les données ne sont pas stockées sur vos serveurs ?

C'est vérifiable techniquement — pas seulement promis contractuellement. Le code source est auditable : la connexion PeerJS établit un canal WebRTC direct entre deux navigateurs.

Les fonctions Cloudflare (check-license, turn-credentials, accept-terms) n'acceptent aucun paramètre de données personnelles. Le serveur TURN de Cloudflare Calls ne fait que relayer des paquets IP chiffrés — il est techniquement incapable d'en lire le contenu (chiffrement obligatoire DTLS/SRTP).

Preuve technique disponible sur demande : schéma d'architecture documenté et accès au code source pour audit.

Que se passe-t-il si Cloudflare tombe en panne ? Nos comptoirs s'arrêtent ?

Cloudflare est l'infrastructure CDN avec la meilleure disponibilité historique : SLA contractuel de 99,99% — soit moins de 52 minutes d'inactivité par an.

En cas de panne partielle, la connexion WebRTC peut basculer automatiquement sur les serveurs TURN. Même sans internet, la procédure classique reste applicable — la solution est un gain d'efficacité, pas un point de défaillance critique.

Pour la vérification de licence, un cache local (localStorage, 30 jours) permet à chaque terminal de fonctionner même si l'API est momentanément inaccessible.

C'est un développeur indépendant — que se passe-t-il s'il arrête de maintenir le produit ?

Question légitime et appréciée. Trois niveaux de protection sont disponibles :

  • Le code source complet est livré avec la licence. Tout développeur web peut reprendre le projet — pas de binaire opaque.
  • L'architecture repose sur des standards ouverts (WebRTC W3C, Cloudflare Workers) — aucune technologie propriétaire non documentée.
  • La pile technique (HTML/CSS/JS vanilla + serverless) est délibérément simple pour minimiser la dette technique et faciliter la reprise.

Le contrat de licence inclut une clause d'escrow du code source sur demande. Pour les grands comptes, un contrat de maintenance pluriannuel est disponible.

Cette solution est-elle conforme au RGPD ?

La conception « zéro stockage serveur » est le meilleur argument RGPD possible : on ne peut pas subir une fuite de données que l'on ne stocke pas.

  • Principe de minimisation (Art. 5.1.c) : seules les données strictement nécessaires sont collectées.
  • Droit de suppression (Art. 17) : données non stockées → rien à supprimer.
  • Droit d'accès (Art. 15) : le client voit en temps réel toutes les données saisies via le résumé de validation.
  • Droit de rectification (Art. 16) : bouton « Modifier » disponible avant la transmission.

Les sous-traitants (Cloudflare, Photon/Komoot) sont conformes au cadre EU-US Data Privacy Framework. Un DPA est disponible.
